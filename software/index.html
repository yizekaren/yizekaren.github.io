Software

Research methods with code you can explore and use. Our group collection is at github.com/Zhao-team ↗.

Yize Zhao · Yale

scMODAL

Single-cell multi-omics alignment

Align single-cell datasets across modalities with deep generative learning and feature links, supporting integrated representations and downstream analyses.

Repository & documentation ↗Paper ↗
Developed by Gefei Wang and collaborators.

BHPI

Bayesian hypergraph inference

Estimate overlapping disease groups and risk-factor associations, with posterior uncertainty.

Repository ↗Paper ↗
Group fork of Naomi-Ding/BHPI.

LatentSNA

Brain–behavior network analysis

Jointly model brain connectivity and behavioral measurements through a latent space framework.

Repository & tutorial ↗Paper ↗Tutorial video ↗
Group fork of selenashuowang/latentSNA.

SF Gradient Coupling

Multimodal brain organization

Construct and analyze structural–functional gradient coupling, including behavioral and genetic associations.

Repository ↗Paper ↗

COSR

Connectivity-on-shape regression

Study spatially varying associations between brain shape and functional connectivity.

Repository ↗Paper ↗
Group fork of Naomi-Ding/COSR.

SBP

Supervised brain parcellation

Construct brain nodes and networks using voxel-level imaging and a behavioral outcome.

Repository ↗Paper ↗
Original implementation by Wanwan Xu and collaborators.

Nebula

Network-based multimodal clustering

Nonparametric Bayesian clustering of multi-view and multimodal data, using network structure to learn groupings.

Repository ↗Paper ↗

BNMM

Bayesian Network Mediation Model

Repository ↗Paper ↗
