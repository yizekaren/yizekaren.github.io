Brain networks & cognition

BSTD

Bayesian deep learning for dynamic connectivity

Link stationary and time-varying functional connectivity to cognition, with posterior summaries of predictive edges, brain regions, and temporal patterns.

Repository & documentation ↗Paper ↗
Python · Biometrics, 82(4), ujag174 (2026).

LatentSNA

Brain–behavior network analysis

Jointly model brain connectivity and behavioral measurements through a latent space framework.

Repository & tutorial ↗Paper ↗Tutorial video ↗
Group fork of selenashuowang/latentSNA.

SF Gradient Coupling

Multimodal brain organization

Construct and analyze structural–functional gradient coupling, including behavioral and genetic associations.

Repository ↗Paper ↗

SBP

Supervised brain parcellation

Construct brain nodes and networks using voxel-level imaging and a behavioral outcome.

Repository ↗Paper ↗
Original implementation by Wanwan Xu and collaborators.

ABCModel

Attributes-informed brain connectivity

Estimate group-level structural or functional connectivity jointly with regional attributes through a latent space model.

Repository & tutorial ↗Paper ↗
R · Alzheimer’s & Dementia.

HyBRiD

Higher-order brain relationships

Learn relationships among groups of brain regions and use the resulting representations for cognitive outcome prediction.

Repository & documentation ↗Paper ↗
Python · ICML 2024.

GenCPM

Generalized connectome-based predictive modeling

Predict continuous, binary, categorical, and time-to-event outcomes from brain connectivity, with optional non-imaging covariates and regularized regression.

R package & tutorial ↗Paper ↗
R · Frontiers in Neuroscience.

COSR

Connectivity-on-shape regression

Study spatially varying associations between brain shape and functional connectivity.

Repository ↗Paper ↗
Group fork of Naomi-Ding/COSR.

CoCR

Repository & example ↗Paper ↗
R · Biometrics.
