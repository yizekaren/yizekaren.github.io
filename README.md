A static version of the public website at **www.yizezhao.com**, prepared on September 13, 2026 for GitHub Pages. It preserves the existing design and all six pages. No Wix account, paid hosting plan, build service, database, or JavaScript framework is needed to serve it.

## Publish on GitHub Pages

1. Sign in to GitHub as **yizekaren**.
2. Create a new **public** repository named **yizekaren.github.io**. This repository should contain only this website's files.
3. Add the contents of this directory at the repository root on the `main` branch, including `.nojekyll`. Do not put them inside an extra `yizezhao-website` directory.
4. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**, and save.
5. Wait for the Pages deployment to succeed. Verify all six pages and the CV at **https://yizekaren.github.io/** before changing the custom domain.

GitHub Pages supports free hosting from public repositories. The domain registration remains a separate paid service.

## Connect the existing domain after publication

Preserve the existing DNS records before editing, including unrelated email and verification records. Keep the domain registration active at Wix.

1. Verify ownership of `yizezhao.com` in the GitHub account's Pages settings using the exact TXT record generated by GitHub.
2. In the website repository's **Settings → Pages → Custom domain**, save **www.yizezhao.com**. When publishing from a branch, GitHub creates the `CNAME` file. Add the custom domain on GitHub before changing Wix DNS.
3. In Wix DNS, point `www` with a CNAME record to **yizekaren.github.io**.
4. Replace the apex domain's Wix website A records with these GitHub Pages A records:

   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`

5. Remove or replace conflicting website AAAA records if present; leave unrelated MX and TXT records intact.
6. Wait for DNS and GitHub's HTTPS certificate to become ready, then enable **Enforce HTTPS**. Verify `https://www.yizezhao.com`, `https://yizezhao.com`, all six pages, and the CV. DNS propagation can take up to 24 hours.

No `CNAME` file is included yet, so the initial GitHub preview will not redirect to the current Wix site. The canonical URLs and sitemap are already prepared for the final `www.yizezhao.com` address.
